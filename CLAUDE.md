# CLAUDE.md

Leé **AGENTS.md**: es la guía única para cualquier agente en este repo.

Resumen: pedido → `python3 voxel.py new -o videos/X/guion.json --line "A: …"` (o un JSON a mano) → `validate` → `preview` → `render` (local o `--cloud modal`). Todos los comandos aceptan `--json`. Las claves y la cuenta de Modal van en `.env`, que nunca se sube.
